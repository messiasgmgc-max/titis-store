# Titi's Consultoria de Imagem - App Mobile (iOS & Android)

Este aplicativo foi desenvolvido em **React Native com Expo (TypeScript)** para entregar uma experiência nativa fluida em celulares Apple (iOS) e Android.

## 🚀 Como Executar Localmente

```bash
# 1. Instalar as dependências
npm install

# 2. Iniciar o servidor de desenvolvimento Expo
npm start

# Para testar no Android:
npm run android

# Para testar no iOS (requer macOS e Xcode):
npm run ios
```

## 📱 Recursos
- **Navegação Nativa de Alto Desempenho**
- **Tema Luxo Dark Mode (Obsidian & Champagne Gold)**
- **Integração com a API NestJS / Supabase**
