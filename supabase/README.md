# Configuração do Supabase para Titi's Consultoria de Imagem

## 📋 Instruções de Configuração no Dashboard Supabase

1. Crie um novo projeto no [Supabase](https://supabase.com).
2. Vá até o **SQL Editor** no painel do Supabase.
3. Copie o conteúdo do arquivo `schema.sql` deste repositório e execute.
4. Em **Project Settings -> API**, copie o `URL` e a `anon key`.
5. Cole as credenciais nos arquivos `.env.local` do projeto `web` e `.env` da `api`.
